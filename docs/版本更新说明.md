## v1.0.2 · 公路隧道 + 双首领

### 新地图：公路隧道（第五张）

- **一条走廊**：两侧衬砌撞不穿、子弹也打不穿，没有房屋、没有岔路。
  刷怪点被收在走廊正中那条带里，尸群只能从前后压过来 —— 被包夹是真的前后夹。
  顶灯三盏坏两盏，光池之间是黑的那一段。
- **杂兵更硬**：血量 +42%、带 13% 抗性（只挡实弹 / 近战 / 爆炸）；经验 x1.45、搜刮 x1.50、通关 140 金，
  解锁条件是通关锈水高速。
- **场景**：衬砌、顶灯光池、横梁黑影、路锥与翻倒的轿车；车壳与箱子照旧可以砸开搜刮。
- **连环追尾（每 1152px 一处）**：五到七辆车挤在一条车道上，其中一两辆横过来、车头顶进车堆，
  有机率是侧翻的；车堆会挡子弹、也能搜刮，旁边永远留着一道 ≥46px 的缝（测试会量）。
  地上有拖了 200px 的刹车痕、碎玻璃、震下来的混凝土块、漏油、干涸的血，以及没跑出来的人。
- **隧道更旧了**：墙皮剥落露钢筋、墙根堆着碎石、偶尔一墙血手印、大面积水渍污浊。
- **照明重做（`src/world/light.js`）**：三个光源，取最亮的那个 ——
  **顶灯**（每 288px 一盏、左右严格交替、半径 190、灯下一大片几乎全亮）、
  **事故车堆的火**（半径 215、暖橙、跟着火苗抖）、
  **玩家自己那圈**（半径 = 经验吸取范围，基础 44 / 满级 86）。
  玩家那圈是保底：坏灯段也不至于连自己的脚都看不见；而**堆拾取范围 = 看得更远**写进了玩法。
- **黑暗是"挖出来"的，不是"蒙上去"的**：挖开的地方是**原画**，所以灯下 / 火边的路面、车堆、
  尸体细节一点没丢（之前是压黑再 `lighter` 补光，等于隔着一层黑玻璃看，用户的原话是"路灯朦朦胧胧"）。
  实现上是**1/2 分辨率的逐像素暗度图**：每个像素取"最亮的光源"（和索敌用的 `Light.vis` 同一条曲线），
  写成一张黑色 RGBA 小图，`putImageData` 之后拉伸盖上去 —— 曲线精确、边缘平滑，
  而且完全不用 canvas 合成。
- **顺手修掉一个微信小游戏崩溃**：最早的实现是离屏画布上铺黑、再用 `destination-out` 按亮度板挖洞
  （浏览器完全正常），但在微信小游戏里会让性能 SDK 递归爆栈
  （`RangeError: Maximum call stack size exceeded @ CanvasRenderingContext2D`）。
  中途试过"矩形 + 逆时针圆"一次 fill 的写法，也是个坑：nonzero 规则下**两个圆重叠的区域**
  winding 变成 −1，反而被填黑，灯与灯之间直接变成一个大黑球。最终换成逐像素方案才两边都干净。
- **事故车堆在烧**：每处追尾固定一辆 `car_burnt_v` 带 `fire: 1`，位置由 `World.accidentFire(k)` 给
  （车堆按 k 缓存）。渲染是三层：暖橙光晕 + 三束不同相位的火苗 + 7 颗上升火星（相位全靠 hash + 时间，不存状态）。
  灯坏掉的那一段就靠它照明。
- **看不见就不能索敌**：`Game.nearest` 只认"看得见"的目标 —— 光圈内 / 灯下 / 火边；
  渲染和索敌读同一个 `Light.vis()`，画面黑到什么程度就打多远。
- **黑暗里会发光的东西**：自爆尸的肚囊、两个首领身上的荧光；首领在光圈外留一层半透明剪影，
  尖啸者的收束环 / 声压环照常画在黑上 —— 黑暗藏杂兵，不藏警告。
- **顶灯重做**：灯从走廊正中挪到**车道边**（x = ±62），用一根短托架连到衬砌上，不再是"浮空的亮条"；
  灯罩 + 两根灯管独立绘制，亮度每帧重算；还有 38% 是坏的（只剩灯罩和一道裂缝）。
  光池压在暗色之上重画，亮的时候能真正"打穿"黑暗。
- **灯闪改成"抖"，不再"爆闪"**：以前"接触不良"是把两段高频 sin 硬切成 0.04 / 0.22 / 1.0 三档，
  每秒跳两三次、幅度接近满亮，整片光池跟着忽明忽暗，看着刺眼（也不像接触不良，像报警灯）。
  现在改成平滑的低频抖动（0.38~0.56）+ 每 5 秒一次"掉电"（用 smoothstep 过渡到三成），
  全程没有硬跳：单帧亮度跳变从接近 1.0 降到 **0.056**。
  "快坏了"那档也从 0.42~0.84 收到 0.40~0.56，火光跳动幅度同时从 ±0.16 收到 ±0.10。
  `check-tunnel` 加了两条断言（单帧跳变 < 0.12、接触不良峰值 ≤ 0.65）防止以后退回去。
- **隧道专属设备**（街道/桥面那套道具在隧道里权重归零）：射流风机（31x12 圆筒，挡子弹）、
  消防箱（砸开翻急救包，血包概率 30%）、疏散指示牌（不挡路，黑暗里一点绿光）、
  橙白防撞桶（车能直接撞碎）。

### 新敌人：自爆尸

- **被打死才炸**：它自己不会走过来引爆 —— 开关在玩家手里。什么时候点掉它、站在哪个角度点，
  是这张图唯一的博弈。
- **冲击波不分敌我**：46 像素内对丧尸满额、对玩家按距离衰减（边缘约五成半），
  一帧最多结算 8 次，够炸穿一小片尸群又不会卡帧；**贴在一起的自爆尸会被连锁引爆**。
- **肚囊是唯一识别点**：那颗肚子在暗处发光，血越少脉冲越急。
- 25 秒后混进尸群，占比缓升到约 1/4；70 秒后呕酸尸补位。

### 新首领：双首领同场（尖啸者 + 育母）

- **两只一起进场**，一上一下把你夹在走廊中间；**两条血条都要清空才算通关**，
  打死一只不结算，另一只立刻顶上来（合计血量 3042，比断堤巨斧更厚）。
- **尖啸者 · 超声改成全向**：不再是前方 ±30° 扇形 —— 只要在视野里、250px 以内就震晕，
  绕到背后同样吃。蓄声 0.55 秒（喉咙收光 + 一道很淡的射程环）→ 掉血 + **眩晕 0.9 秒**。
  应对方式从"横移躲锥形"改成**躲到车壳后面断视线**，或者跑出射程。
- **尖啸者 · 长啸（新技能）**：蓄 0.5 秒后持续尖啸 2.4 秒，每 0.32 秒补一次短眩晕 + 掉血，
  被锁住就站不起来；一旦视线被车挡住立刻收声，之后 12 秒是输出窗口。
- **育母 · 抓投（新技能）**：把身边的自爆尸抓起来扔向玩家 —— 起手伸手（0.5s）→ 甩出，
  自爆尸在空中翻滚（地面只留影子）落地即炸，爆炸倍率 ×1.3。留着自爆尸 = 给育母攒弹药。
- **双首领更耐打**：尖啸者 1800→2000 血 / 护甲 0.12→0.18；育母 2100→2400 血 / 护甲 0.20→0.24；
  关卡对首领的减伤 `bossDmgCut` 0.30→0.34（合计有效血量约 +27%）。
- 贴身改用骨爪横扫。
- **育母 · 产崽**：育囊绷紧 0.9 秒后一口气挤出 **3 只小自爆尸**（体型 62%、血量三成、炸得更轻），
  逼你在"继续输出"和"先清崽"之间选；贴身用育囊撞。
- **眩晕是全游戏唯一会夺走操作权的负面状态**，所以只有这一只怪会，冷却 6.4 秒，
  开车时只吃三成（车窗和引擎声挡掉大半）。

### 修正：冰火两重天的配方 / 描述 / 实现三处对不上

- **卡面写错**：描述原来是"被冻结的敌人受到的中毒伤害 +40%"，但实现判的是 `tag === 'auto'`
  （毒雾只是其中一件自动装备，无人机、炮塔、地雷同样吃加成）。
- **配方少一半**：卡叫"冰火两重天"，配方却是"冰霜环 + 毒雾"，里面没有火。
  现在改成"冰霜环 + **火焰环或毒雾**"，并且实现同时认 `tag === 'fire'`
  —— 冰霜环冻住、火焰环/喷火枪烧过去，那才是冰火两重天。
- 描述同步写成"被冻结的敌人受到的**火焰与自动装备**伤害 +40%"。
- 顺手补了两处判定：`synMissing`（差一件时提示缺哪件、拿卡时补给你）和 `checkSynergies`
  （真正决定联动是否生效的地方），否则会出现"只有冰霜环就自动生效"或"凑不齐永远刷不到卡"。
- `smoke` 加 6 条断言：只有冰霜环不成立 / 冰+火成立 / 冰+毒成立 / 冻结目标吃 auto +40% /
  吃 fire +40% / 近战不受影响。

### 水鬼加强：出水那一拍打不中

- **问题**：水鬼血量 26（锈水高速折算 32），中期玩家一秒能打掉两百。它辛苦潜过来、
  咬完一口（8 点伤害）之后就站在玩家脸上，0.2 秒内必被清掉 —— 整张图里它退化成"会送经验的怪"。
- **为什么不是加血量**：1 级到中期，26 提到 50 也只是把存活从 0.16 秒变成 0.31 秒，还是瞬间。
  要"扛得住一梭子"得翻五倍，那它就成了锈水里最肉的杂兵（比壮汉 78 血还肉），定位整个漂移。
- **改成 0.35 秒的出水保护（`emergeGuard`）**：从浮出到落地这一拍打不中，
  让它可以**咬完退回水里**，而不是站在原地等死。血量一点没动。
- **必须画出来**：身上裹一层淡青色水膜（画在精灵下面，读起来是"糊了一身水"而不是远处的光环），
  一直淡出到保护结束。不画的话玩家只会觉得"我这几枪丢了"。
- **爆炸是例外中的例外**：榴弹把它震出水面的路径**不给**保护 —— 爆炸本来就是逼它出来的手段，
  震出来还打不动就成了负反馈。
- 实测锈水高速平均存活 320s → **274s / 305s**（两组各 10 局，均值约 290s）：提升约一成。
  幅度还在随机波动范围内，方向是对的，但**不足以解决第 4 关偏易**（根因是水域把尸体挡在外面，
  见 `docs/关卡难度分析.md`）。这轮没有加血量就是这个原因 —— 加血同样治不了根。
- `check-flood.js` 加 5 条断言：出水不再算水下 / 进入保护 / 保护期内打不死 / 窗口约 0.35 秒 / 之后照常结算。

### 红莲的「加宽光栅」：穿透折成宽度

- **穿透对持续光束是"有效但没用"**：实测 `pierce 2 → 命中 3 个`、`pierce 5 → 命中 6 个`，
  机制上确实生效。但实战里僵尸很少排成一列，第四个目标几乎不存在 ——
  这张卡的穿透部分等于白送。
- 它的真正瓶颈是**线有多宽**（能不能同时罩住并排的两三只），所以对 `sustainBeam` 武器
  把「加宽光栅」的 `pierce +1` 折进 `width`：`width +2, pierce +1` → `width +3`。
- **激光步枪 / 轨道炮不动**：它们是窄而快的光束，一列怪对它们很常见，穿透仍然有效。
- 卡面文案同步改（"光束大幅加宽"），不然玩家还会以为能多穿一个。

### 红莲进化：从"穿透"改成"持续灼烧"

- **问题**：熔核过载（红莲切割者 → 进化）原来只有 `dmg 1.45 / width 1.3 / range 1.15` 三个乘法，
  打起来和本体的区别就是"数字大一点"。中途给过 `pierce +3`，但那个也不对 ——
  **本体那道光束本来就沿着直线打穿一整排**，再给穿透等于把"本来就能做的事"重复卖一次。
- **现在换成两样本体没有的**：
  - **`melt` 熔核层数**：同一目标被连着照，每跳 +9% 伤害，最多 8 层（+72%），
    **断火 0.5 秒清零**。持续光束 12.5 跳/秒 → 0.64 秒叠满，打 BOSS 时能明显看到数字在涨。
  - **独立音色 `meltlaser`**：从"一束脉冲"变成"一直在烧"。
    噪声拖长到 0.10 秒、中心频率压到 2600→820（更闷），主音调 1650 慢慢滑到 560，
    再垫一层几乎不动的低频方波当底；播放间隔也从 0.16 缩到 0.11，前后两发叠着听才像没断过。
  - 配色 `#ff3b30 → #ff9b82`（烧到发白）。
- **`art` 不能直接改**：它同时决定枪械外形（`render` 的 `ART_KIND`），
  所以在 `Gear.fire` 的音效调用处单独判 `flags.melt`。
- **数值**：本体 5 级 63.5 DPS（机器人木桩）→ 进化 1 级 **83.7**（+32%），满级 104.8。
  进化是从满级本体变来的，所以该跟"本体 5 级"比，不是跟本体 1 级比。
- `smoke` 加 4 条断言：带熔核标记 / 不靠穿透当卖点（pierce 与本体一致）/ 换了配色 / 熔核会叠层且断火清零。

### 断堤巨斧：交叉斩的地面破坏改成「沿刀口的弧裂纹」

- **以前**：两道斧各自在斧尖位置砸一个**圆形坑**（`Water.breakTerrain`）——
  圆坑读起来是"砸"的，可交叉斩是"挥"过去的，两种招式在地上留下的痕迹一模一样，
  玩家分不出刚才挨的是哪一招。
- **现在**：新增 `Water.crackArc`，在 `run.breaks` 里存一条**弧裂纹**
  （圆心 = BOSS 站位、`ang` = 斧挥出的角度、`span` = 判定半角 ×2 = 1.72 弧度、`r` = 判定半径 118）。
  - 画法是沿弧线采样 20 段，半径只抖 ±3%（±7% 会抖成拉链），
    内侧补一道受光边，再挑 4 处短分叉甩出去。
  - 碎石沿弧线飞出，不是四面崩开 —— "划"和"砸"的粒子方向也该不一样。
  - 同一处连砍只续命加长；**去重必须带角度**，否则一次两斧（`aAim ± 0.46`）
    因为圆心半径相同会被并成一条。
- **半径 = 伤害判定边界（118）**：`r` 与 `span` 现在和判定读同一组常量
  （`CL_R` / `CL_HALF`，见 `combat.js` 的断堤巨斧分支），不是斧刃视觉长度（92），
  也不是"多近才起手"的 132。裂纹圈住"这一刀能砍到哪"，站在弧外面就是安全的 —— 这层信息对走位有用。
- **弧不压扁**：贴地装饰（车底阴影、圆坑放射纹）习惯乘 0.62 做透视，
  这条弧不能跟着压 —— 判定是正圆，压扁之后弧的上下两头只剩 62% 半径，
  玩家站在"弧外"照样被砍到。裂纹和碎石都改成正圆采样，和判定同形。
- **跃劈保留圆坑**（砸地本来就该是坑），两招在地上现在能分辨。
- `check-flood` 加断言：留下弧裂纹 / 两道斧不被合并 / 有角度和弧长 / 弧长铺满判定扇形 /
  **玩家站在 117.5 会掉血、站在 118.5 不掉血**、裂纹半径等于这条边界。

### 修正：水鬼把玩家一路拖进深水，导致卡关

- **现象**：水鬼反复咬，玩家被一路往深水推，最后停在离公路几十米的水中央。
  深水里玩家 0.30 倍速、普通丧尸 0.34 —— **玩家比怪还慢**，走不出来；
  而深水又把丧尸挡在外面、BOSS 也过不来，于是既打不到东西、也死不掉，整局卡死。
- **根因**：`dragToWater` 只看方向、不看玩家当前站在哪。人已经在水里了，它还在往更深处推。
- **三条修正**：
  1. **已经在深水里就不再拖** —— 拖到水里它的目的就达成了，剩下该玩家自己往回爬。
  2. **拖到深水边缘就顶住，不把人推进去**（每帧检查下一格水深，进水就松口）。
     这一条是关键：深水对玩家是死局，不能让一个技能直接把玩家送进去。
  3. **松口后 2.5 秒免疫**（`p.dragImmune`，从触发算起是 拖拽 1.4 + 2.5 = 3.9 秒），
     防止几只水鬼接力拖。
- **连带回调**：水鬼占比 `0.22 → 0.14`、呕酸尸 `0.36 → 0.32`。
  它现在能一路潜到脚下、出水那一口也不再咬空，单只强度比过去高一档；
  密度不降的话，锈水高速的机器人平均存活会从 286 秒掉到 **121 秒**。
- 实测：**175 秒**（第 3 关 174 秒、第 5 关 132 秒之间，曲线仍然单调）。
- `check-flood` 加 4 条断言：已在深水不拖 / 第一口能拖、第二口不叠加 / 免疫覆盖拖拽+冷却 /
  连咬 12 次既不越拖越远也不会被拖进深水。

### 升级三选一：进化卡改用炫彩流动边框

- **问题**：进化卡原来只是金色描边 —— 而「稀有属性卡」也是金色，
  同屏出现时完全分不出来。玩家经常在这次能进化的时刻，顺手点了旁边的 +12%。
- **做法**：进化卡单独画一圈**彩虹渐变描边**，渐变轴绕卡片中心旋转（`uiT` 驱动），
  颜色沿边框流动；外面再垫一层外扩 3px、透明度 0.22 的同色辉光。
- **三个坑**：
  1. 边框**必须和 panel 同位置同半径**（`cx, y, cw, chh, 16`）。差 1px 就会露出底下那条金色描边，
     顶部显出一道发白的毛边。
  2. 进化卡**不再画 panel 的金色描边**（传 `null`）—— 两条线叠在同一条路径上，
     抗锯齿饱和之后一样会发白。
  3. 辉光层要**垫在卡片外面**，和主描边同位置会三层叠加，同样发白。
- `smoke` 加一条渲染回归（旋转渐变 + 三层描边不能画崩）。
- 顺带确认 `Game.uiT` 在 `levelup` 状态下照常递增，所以边框是真的在流动，不是静态渐变。

### 水鬼：潜到脚下 + 往深水拖人

- **潜行时长按距离给**：以前固定 1.5 秒，而它 34×1.75×1.5 只能游 **89px** ——
  可是从 250px 外就会起潜，于是经常"潜到一半自己浮上来"，在半路上挨打。
  玩家看到的就是"水鬼技能够不着人"。现在按下潜那一刻的实际距离算时长
  （`(距离-12)/速度 × 1.3`，1.3 是转向损耗的余量），上限 4.8 秒，**能一路潜到脚下再出水**。
- **修掉"贴脸浮出却咬空"**：出水阈值原来是 20px，而咬击判定是 `e.r + p.r + 8 = 18.5` ——
  出水那一刻 dpd 刚好落在 20~22，差 1.5px 就吃不到那一口。阈值改成 18。
  这一条比潜行距离更关键：它把咬击命中率从"几乎全空"变成了"几乎必中"。
- **新增拖拽**（`Game.dragToWater`）：咬中之后不松口，把玩家往**最近的深水**拖 1.4 秒。
  - 伤害只有 5 点，真正要命的是位置：深水里玩家只剩三成移速，被拖进去基本出不来。
  - **玩家的操作不被剥夺** —— 只是一段持续位移，摇杆随时能对抗，枪照常能开。
    这和尖啸者的眩晕是两种东西（后者连开火都封）。
  - 速度 48：**低于步行速度 64**（干地上跑得掉）、**高于深水移速 22**（进了水就动不了）。
  - 只找 170px 内的深水定方向；楼顶 / 车里不拖。
  - 几只水鬼同时咬只刷新时长、不叠加速度，不会把人钉死。
- **伤害与频率同步回调**：`dmg 8 → 5`、`subCd 4.2 → 6`。
  只改前两条时机器人平均存活从 286 秒掉到 **99 秒**（咬击从全空变必中，强度翻了三倍），
  加上拖拽这一版回到 **229 秒** —— 它现在靠位置压制，不靠一口咬死。
- `check-flood` 加 10 条断言：潜行时长随距离拉长 / 从远处能潜到脚下并咬一口 /
  出水点贴着玩家 / 拖拽触发 / 方向指向深水 / 速度低于步行高于深水 / 不是眩晕 / 楼顶与车里不拖。

### 连锁闪电：改成全局最快间隔，并写进描述

- **以前**：限速是靠 `if (!def.sustainBeam)` 把持续光束**整个排除**在连锁闪电之外 ——
  结果是红莲切割者拿了这张卡完全无效（能点出来，但一次电弧都不放）。
- **现在**：闸门放进 `Game.chargeChain` 内部，**所有武器统一**：蓄能照常按开火次数累积
  （一次齐射只算一次），但两道电弧之间至少隔 **0.45 秒**。攒到顶之后等闸门开，一开立刻放。
- 所以高频武器（持续光束 12.5 跳/秒、冲锋枪）不会把电弧刷成一条线，
  低频武器（狙击、重型）也不受影响 —— 这是"同一把尺子"，比单独排除某把枪公平。
- **描述同步写清**：卡面现在写「最快每 0.45 秒一道，射速再高也不会更快」。
  不写的话玩家会按射速去估收益，实际被闸门卡住，感觉像"卡没生效"。
- 实测：红莲切割者 3 秒内 6 道（原来 0 道），最小间隔 0.48s。
- `smoke` 3 条断言：持续光束也能放电（不再被排除）/ 最小间隔 ≥0.44s / 3 秒不超过 7 道。

### 红莲切割者：补伤害

- **问题**：满级单体 DPS 51.1，全部手持武器里最低（手枪都有 47.5，龙息 61.2）。
- **根因**：它是唯一不吃攻速的武器（`sustainBeam` 分支固定 `w.timer = def.base.cd`，
  绕过整个 rate / cdr / 暴走 / 过热体系），成长也只有 `dmg` 一条腿
  （`g` 里没有 `cd`），所以 1→5 级只涨 **1.65 倍**，是全武器最低成长率。
  别的枪五级能涨 1.8~2.1 倍，因为它同时拿到"伤害"和"射速"两份成长。
- **修法**：`dmg 2.0 → 2.2`、`g.dmg 0.16 → 0.21`（纯数值，不动"不吃射速"的身份）。
  实测 31.0/51.1 → **34.1/62.3**，成长率 1.65 → 1.83，和龙息（34.3/61.2）持平。
- **攻速折算（`SUSTAIN_ATK2DMG = 0.6`）**：它不吃攻速，但攻速收益不能凭空蒸发 ——
  玩家点了一堆攻速卡对这把枪毫无反馈，只能觉得是废卡。
  现在「攻速 / 冷却缩减 / 暴走 / 过热」这些本该让它打得更快的收益，
  统一按**六折折成这一跳的伤害**（走 `w.chargeMul` 一次性倍率通道，不写进 stat 缓存）。
  打六折的理由：它是"永远不断火"，本来就不该等价于同倍率的爆发。
  实测攻速 ×1.3 → DPS ×1.17、×1.6 → ×1.33、×2.0 → ×1.60，和理论值一致。
- **注意别用 `st.cd` 做比值**：`st.cd` 里掺了 `BASE_CD`（1.14）和 0.04 下限，
  `def.base.cd / st.cd` 会恒小于 1，等于一点加成都没有。要用 `p` 的原始属性算。
- 卡面描述同步：*「不吃射速——但多出来的攻速会按六折折算成伤害」*。
- 新增 `tools/dps.js`：单木桩、站定、关暴击，量 1 级 / 5 级的真实直伤 —— 以后调武器数值先跑它。

### 火焰喷射器 / 液氮喷枪：降直伤，把重量挪到"烧"和"冻"上

- **实测（满级单体 DPS）**：液氮 90.9、喷火 70.1 —— 全场最高的两把，
  而它们本来该是"靠状态压制"的武器。液氮尤其滚雪球：先手挂上减速后，
  后续每一跳都吃"已冻 1.45 倍"，越喷越痛。
- **火焰喷射器**：`dmg 5.5 → 4.6`（−16%），同时把点燃系数 `1.2 → 1.4`
  —— 直伤降了，但这把枪该让"烧"来干活，挂着火时 dot 的占比反而更高。
  实测 37.9/70.1 → **33.0/59.4**。
- **液氮喷枪**：`dmg 4.6 → 3.8`（−17%）、已冻倍率 `1.6 → 1.45`、
  减速 `0.45 → 0.50`（减速加强，补偿直伤）。实测 52.4/90.9 → **38.8/68.9**。
- 两把枪的定位因此更清楚：贴脸直伤不再是主要输出，**火靠持续灼烧、冰靠把尸群拖慢**。

### 修正：「双发扳机」挂着一个没人读的 special

- 这张卡的效果是 `count +1`、`spread +0.04`（"每次多打出一发，散布略增"），
  数值上完全实现了描述，但它还额外挂着 `special: 'volley'` —— 代码里**没有任何地方读它**。
- 更麻烦的是 `smoke` 里那条"special 必须有消费方"用的是**手写白名单**，
  `volley` 就在白名单上，于是这个死字段一路绿灯。
- 现在字段删掉了，白名单里那一行也删了。副作用是「多数装备带改变机制分支」的真实覆盖率
  从虚高的 70% 掉到 55%（阈值同步改成"过半"）—— 这才是实话。
- 新增 `tools/check-fields.js`：不再靠白名单，而是**直接扫源码**，
  字段名必须在 gear / combat / auto / game 里真的被读到；顺带查持续光束没有绕开连锁闪电。

### 修正：范围持续输出对潜水中的水鬼无效

- **问题**：水下无敌只写在 `hurtEnemy` 一处，直伤确实被拦住，但**点燃 / 减速 / 冻结标记
  是在调用点无条件挂上去的**。结果是：拿喷火枪对着水面喷，水鬼一滴血不掉，一浮出来却带着火；
  液氮更离谱 —— 不掉血，但挂着 0.45 减速和 `synFrozen`，出水就吃「霜火反应」和「冰火两重天」的加成。
- **影响面**：喷火枪 / 液氮 / 龙息（`gear.js` 的 `Gear.flame`）、火焰环 / 冰霜环（`auto.js` 的 `Auto.ring`）、
  火焰喷口、区域型火池毒池、地面火池（`combat.js` 的 `updateFx`）、光束的点燃（`Gear.beamOnce`）。
- **修法**：在这些范围判定里直接跳过 `e.submerged`，和 `hurtEnemy` 同一条规则。
  水下**只有爆炸**能作用 —— 爆炸那条路径会先把它震出水面（`submerged = false`），
  所以它接着吃冰冻手雷的减速是合理的，不用特殊处理。
- `check-flood.js` 加 7 条断言：喷火 / 液氮 / 火焰环 / 冰霜环 / 地面火池都对水下的它无效
  （血量、燃烧、减速、冻结标记四项一起校验），以及"出水后照常点着"的对照。
- 难度影响很小（锈水高速 274 / 305 / 286s，三组均值 288s）：潜水只有 1.5 秒，本来就是窗口期。

### 新增：扑袭者进隧道

- **死区之夜的扑袭者（会蓄力猛扑）现在也进公路隧道**：100 秒后进场，占比 0.08
  （隧道另外两种专属怪都是 0.16 起），180 秒后约 7.7%。
- **压着放的理由**：它本来是街区怪，街区左右各有几十像素可以侧滑躲开；
  隧道走廊只有 |x|<88、尸群又从前后压来，同样一次猛扑在这里几乎躲不掉。
  所以给它的面额最小、出场最晚（那时玩家通常已经有自动装备可以挡一下）。
- 实测 10 局平均存活 132s（加之前 130s）—— 有存在感，但没破坏平衡。
- `check-tunnel.js` 加 5 条断言：90 秒前不出现 / 150 秒后混入 / 占比 <15% /
  仍带 `pounce` 机制 / 隧道专属怪合计 ≤42%（防止走廊变成"精英开会"）。

### 装备：两件环的视觉分家（冰霜环改冷蓝）

- **问题**：冰霜环在数据表里挂在「环绕型」分组下，颜色和图标直接继承了分组的默认值（橙 `#ff8b3d` + `firering`），
  于是它和火焰环在卡面、HUD、场上长得一模一样，只能靠名字分辨。
- **新图标 `icerim`**：同一个环，环内是一根竖冰晶 —— 不用雪花，是为了不和「低温专精」的 `frost` 撞脸。
- **场上靠"环上长什么"分家**：两环半径只差 4px、经常同时挂在身上，光换色相不够。
  冰霜环的描边提到 0.80、加一层贴地的淡霜气（火是往上走的，冰才往四周铺），
  环上钉**八颗白十字冰晶**（原来是 2px 的小十字，等距看只是几个白点）；火焰环仍是往上窜的橙色火星。
- **联动卡 `ringIce`（冰火两重天）**：卡面图标以前写的是 `'frostring'` —— 那是装备 id，不是点阵名，

- `smoke` 加 5 条断言：两环颜色不同 / 图标不同 / 图标都有点阵 / 冰偏冷色 / 火偏暖色。

### 装备：嗜血改成群体吸血

- **嗜血（近战专属卡，3 级）**：以前是"每次挥砍封顶 0.6~1.8 点"，一刀扫五个和扫一个回得一样多。
  现在按目标逐个结算：第 n 个目标按 `0.75^(n-1)` 衰减，扫五个约等于扫一个的 3 倍。
  每个被吸到的目标都会甩两滴血朝玩家飞回来 —— 群吸这件事终于看得见。
- **图标换成血滴**：原来的十字（`regen`）读起来像"回血药"，新的 `blood` 点阵是一滴往下坠的血，
  配色也换成暗红 `#e0453c`。

### 空投落点与丧尸寻路

- **空投不再掉进地里**：以前空投/补给按极坐标算一个点就直接生成，隧道两侧是山体，
  有一半概率落进墙里（信号柱在衬砌里面，玩家永远拿不到）。新增 `Game.dropSpot()`：
  隧道先把 x 收回走廊（两侧留 14px），再整体螺旋找一个不压实的点；精英宝箱也走同一条路径。
- **丧尸不再被车堆卡死**：车堆是几块旋转矩形拼出来的凹形，原来的"切向脱困"左右方向靠 uid 奇偶终身固定，
  在死角里会一直往墙上蹭（实测 16 秒走不出来）。现在：
  ① 脱困方向改成**探针**（左右各打三条射线，哪边空往哪边走）；
  ② 侧滑角度改成近 90°（纯沿障碍面滑），并且"滑到直线通了才收工"，不再固定 0.5 秒就放弃；
  ③ 加了 8~12px 粗网格的局部寻路 `World.route()`（和楼体那套 nav 分开）；
  ④ 兜底看门狗：卡 2.5 秒 / 4 秒没有进展，就挪到最近的一块空地（只在离玩家 70px 外生效）。
  回归测试：车堆前方放 12 只丧尸，16 秒内必须至少 10 只能绕到玩家身边。

### 听感

- 新增四个专属音色，不再借通用音效：**超声尖啸**（蓄声是一段往上爬的气、放声是气声 + 高频下滑 + 胸腔低鸣三层）、
  **育囊湿响**、**自爆尸爆开**（比油桶的 boom 更短更闷，小崽再轻一档）、
  **眩晕耳鸣**（一条几乎不衰减的高频细线，跟着眩晕时长走）。
- `tools/sfx-level.js` 电平表补齐这四个；`tools/check-tunnel.js` 加断言，防止以后又退回 zap / boom。

### 修正：开火音和开火对不上（红莲切割者空放 / 慢枪随机静音）

- **红莲切割者 / 熔核过载：没目标时不再"空放"**。以前这一支不看目标，照样每 0.08 秒走一次
  `Gear.fire`：伤害 0、画面上一道光都没有（`p.beamHold` 没目标就不续），但每 0.16 秒有一声
  "激光一直在烧"，连锁闪电还跟着空枪蓄能。现在射程里没人就一下都不打，计时归零 ——
  目标一进射程立刻接上，不用重新起燃。有目标时的伤害、跳数、音色一律不变。
- **红莲的声音改成"一直响"，不再是噼啪的脉冲**。它的特效是一条不断的光，声音却每 0.16 秒
  打一发 0.07 秒的激光音 —— 6Hz 的断续听起来像"还在扣扳机"，和"持续灼烧"正好相反。
  现在是一层常驻声部（`Audio.beam`）：两只差 0.7Hz 的锯齿过 1100Hz 低通（拍频是很慢的起伏，
  不是鼓点）+ 八度三角 + 一层带通白噪当气流；熔核换成 84Hz / 620Hz 低通 / 更暗的气流。
  增益 0.2 秒起、0.26 秒落，中间一直是平的；**点亮那一下才补一声激光音**（熔核用 `meltlaser`），
  之后不再一发一发地响。
  音量按"不要太吵"压在 pickup 的 **-3dB（红莲）/ -2dB（熔核）**，比任何一发枪声都低
  （`tools/sfx-level.js` 新增 `beam:red` / `beam:melt` 两行电平表）。
  防卡死：每帧续一次时间戳，停手 0.32 秒没续期就自己淡出并停节点 ——
  暂停 / 结算 / 卸枪 / 上车 / 切后台 / 关音效都不用各自挂一遍 stop，
  漏挂一处就是一条永远停不下来的嗡鸣。
- **慢枪不再随机静音**。弹道武器原来统一 25% 概率不发声（本意是让高射速武器别糊成白噪音），
  可狙击 1.45 秒一发、破城者 1.89 秒一发，抽掉一发就是"扣了扳机没声音"。
  现在只有开火间隔 < 0.25 秒的快枪（冲锋枪 / 机枪 / 加特林）才抽稀，其余一发一声。
- **新增 `tools/check-fire-sfx.js`**：136 件手持装备（含全部进化形态）逐个跑
  「无敌人 / 敌人在射程外 / 有敌人 / 目标中途被清空 / 断了再点亮」五种场景，
  断言 ① 音效必须落在这一帧真的发生了攻击的那一帧、② 会开火的武器都得有声、
  ③ 慢枪一发一声、④ 红莲每帧都在续期且只点一次火、⑤ 目标一消失嗡鸣立刻停。
  `tools/check-audio.js` 另加了常驻声部的节点断言（只建一次、停光必须 stop 全部发声节点）。

### 电磁轨道球：过载放电要麻一圈

- **现象**：球确实在周期过载（2.4 秒一轮、满级 1.6 秒），但放电只结算 `pulseMax` 个目标
  （4 / 6 个），**完全不带麻痹** —— 球在过载，旁边站着的怪照常往前挤，
  周围一圈只有四五只有反应，读起来不像"发电"。
- **改法**：过载那一帧把 `radius + 球体 + 16` 这一圈（和地上那圈电环同一个半径）内的敌人
  **全部麻痹**，被电弧打到的（含环外 90px 那个补位目标）也一起麻；
  每人补两颗向外的电火星 —— 敌人被麻只是"停住"，没有这点蓝光很难看出是谁被电了。
- **数值**：`pulseStun` 0.55 秒，满级 0.75 秒（1.6 秒一轮 → 接近一半时间按着贴脸的怪）；
  `Gear.stat` 的满级终形态补上 `full.pulseStun`。
- **回归**：`smoke` 新增 6 条断言 —— 6 秒至少两轮过载、环内一圈全麻、环外 140px 不麻也不掉血、
  麻痹会结束（不是永久定身）、满级 1.6 秒 / 0.75 秒。

### 回旋刃的嗜血不生效（弹体没抄 leechLv）

- **现象**：回旋刃能点「嗜血」，但刀打中人一滴血都不回。
- **原因**：嗜血只在 `Gear.swing`（挥砍）和 `Gear.thrust`（突刺）两条路径里结算；
  回旋刃走的是 `Game.shoot` → 弹体 → `hurtEnemy`，这条路完全没读 `st.leechLv`。
  和当年 `shard` 漏抄弹体是同一类坑：**统计层有值 ≠ 弹体会带上**。
- **修法**：`Gear.fire` 的 boomerang 分支把 `leechLv` 抄进弹体 → `Game.shoot` 存到 `b.leechLv` →
  命中段按 `b.dmg × 0.018 × 等级 × 0.75^第几个目标` 回血，并甩一滴往身上飞的血（复用 `Gear.leechTrail`）。
  衰减口径和挥砍完全一致，所以"一把刀扫一片"不会回一管血。
- **卡面**：「嗜血」的描述从"挥砍命中几个"改成"命中几个"（回旋刃是扔出去的，不挥砍）。
- **实测**：单个木桩 4 秒回 **+13 HP**（≈3.3 HP/s），与武士刀点满嗜血同一量级（≈4.9 HP/s）；
  `smoke` 新增两条断言（等级进数值、真的回血）。

### 回旋刃：撞墙不掉刀，回程直接回手

- **现象**：扔出去的刀碰到墙 / 车就没了，经常"回不来"；偶尔回来了，也是在离身体三十多像素的地方凭空消失。
- **原因**：`updateBullets` 的掩体判定对所有弹体一视同仁 —— 撞建筑、废墟、路边车就 `b.dead = true`，
  回旋刃也不例外；回程同样吃这条，所以"回来的路上被车壳挡住"是最常见的丢刀方式。
  收手距离又定在 34px（≈ 9rad/s 的转弯半径），刀绕到那个位置就被抹掉，看起来像半路消失。
- **修法**：
  ① **去程撞掩体不再掉刀**：退回这一帧的起点（别卡进墙里）、速度反弹并直接进入回程，冒一点金属火花；
  ② **回程不吃掩体**（`b.returning`）：宁可穿过一块车壳，也不把刀吞掉 —— 回手优先；
  ③ **真的回到手上**：贴身 60px 内转身速度提到 40rad/s（转弯半径 ≈ 6px），收手距离 34px → 16px；
  ④ 渲染给回旋刃加一截 7px 尾迹，去程 / 回程 / 撞墙掉头都看得懂。
- **实测**：朝 88px 的车扔 → 0.68s 收回，最近 3.8px；朝 142px 的墙扔 → 撞上弹回，1.53s 收回，最近 2.2px。
  `smoke` 新增 5 条断言（朝车 / 朝墙各两条 + 场景里必须找得到掩体）。

### 回旋刃掉帧：刀回不来 + 顿帧被刷成常态

- **现象**：拿回旋刃主武器打一会儿就掉帧，越打越卡。
- **原因一：刀永远回不了手**。折返阶段为了"回来之前一直有判定"，把 `life` 托在 0.08 以上 ——
  于是它永远等不到"寿命耗尽"那一刻。空放 / 少怪的时候一轮 3 把全留在场上：
  **实测 0 敌人 25 秒攒了 90 把**（线性增长，100 秒 360 把），
  每帧要逐把扫全场敌人、逐把绘制。有怪时刀会靠命中耗掉，所以只在"清完一波"之后悄悄攒起来。
  现在回到手上（34px ≈ 9rad/s 转身的转弯半径）就收，另加 2.2 倍名义时长兜底；
  发射时再兜一层"场上最多 `count×3+3` 把"。空放 20 秒峰值稳定在 6 把。
- **原因二：近战顿帧被刷成常态**。单次伤害 ≥ 目标最大血 15% 的近战命中会顿帧 50ms，
  以前只限制"一帧最多一次"；回旋刃一整套飞出去、每帧都在刮新目标，
  于是 10 秒里 **40% 的帧都在顿帧，世界时间只走真实时间的 0.64 倍** ——
  看起来就是一直在掉帧 / 慢动作。现在：
  ① 弹体命中的近战（飞出去的刀）不触发顿帧，挥砍照旧；
  ② 顿帧本身加 0.4 秒冷却，最多每 0.4 秒"顿"一下。
  实测回旋刃 0 帧 / 10s、世界时间 1.00 倍；武士刀仍有 60 帧 / 10s（顿帧保留，0.91 倍）。
- **回归**：`smoke` 新增 4 条 —— 空放 20 秒刀不超过 12 把、有敌人时照样打到人且不攒刀、
  回旋刃不再触发顿帧、挥砍的顿帧还在但不会刷屏。

### 震屏：自爆尸压低 + 连续震动疲劳

- **自爆尸的震屏从 6 降到 3.2**（小崽 3 → 1.5）。公路隧道一次能引出五六只连环炸，
  原来每一发都把镜头顶回 6px、屏幕一直在抖，一串炸下来"看见什么全靠猜"。
- **新增震屏疲劳**：`run.shakeBusy` 在屏幕**连着**抖的时候累加（1.4/秒），
  `R.shakeAmount` 按它最多打掉六成幅度。单次爆炸只抖 0.1 秒，疲劳还没来得及攒起来，
  所以"一炮"的手感完全没变；停手后疲劳按 0.9/秒回落。
  只影响镜头抖动的显示幅度，不改 `run.shake`、不改任何伤害与判定。

### 修正：光剑无人环的「外扩轨道」把贴脸的怪让开了

- **现象**：点「外扩轨道」之后光剑环整体往外挪，贴脸的丧尸反而落在**环内的空心区**里切不到 ——
  越强化越防不住贴脸，和"环绕武器就是用来防贴脸"的设计正好相反。
- **根因**：光剑的判定是**线段**（`Auto.orbit` 的 `segDist2`：以轨道线为中心，往内 40%、往外 60%），
  而「外扩轨道」改的是半径 —— 半径 +14% 连内沿一起往外推。
- **修法**：给光剑无人环单独一套分支（`gearUpOverride.saberring`），把「外扩轨道」换成
  **「加长刃身」（刃身 +8 / 级，最多 +16）**：外沿照样往外长，内沿朝身体方向长，
  半径不动。实测内沿 36.4 → 31.6px，20px 的贴脸敌人从"切不到"变成"切得到"。
- **连带修掉一个吞分支的 bug**：满级终形态以前是 `st.blade = def.full.blade` 直接赋值，
  会把满级前点过的「加长刃身」吞掉；现在改成 `Math.max`（刃长是加法字段，终形态给的是保底）。
- `smoke` 加 6 条：分支改名 / 满级也吃得到（26 → 30 → 38px）/ 半径不变 /
  内沿往身体靠 / 20px 贴脸怪在没点分支时切不到、点了就切得到。
  另外把 `blade` 补进"分支字段白名单"（它确实是可用字段：`ADD_KEYS` + `Auto.orbit` 都在用）。

### 改：熔核过载（红莲进化）变成一道持续不断的粗激光

- **以前**：数据上早就是 `sustainBeam`（12.5 跳/秒、不吃射速），但**画面上**每跳往
  `run.chains` 塞一条 life 0.12s 的线 —— 12.5Hz 闪下来读起来就是"还在扣扳机"，
  和"持续灼烧"的设定正好相反；而且「多重光栅」还能把它变成 2~3 道并排的细线。
- **现在**：
  1. **常驻光束**：`p.beamHold` 每帧续满（角度做插值 —— 换目标是扫过去，不是瞬移），
     渲染走新的 `R.drawBeamHold`：外晕 → 主体 → 白芯 + 枪口汇聚点，一直亮着。
     没目标 / 上车 / 眩晕时 0.16 秒内淡出（衰减放在 `Game.updateRun`，
     因为驾驶和眩晕时 `updateWeapons` 根本不跑，放那儿光会冻在屏幕上）。
  2. **数量恒为 1**：`Gear.beam` 对 `sustainBeam` 钳死 1 道；「多重光栅」从红莲的分支里换掉，
     改成「长程聚焦」（射程 +10%、穿透 +1）—— 否则它在新规则下就是一张纯负收益的废卡。
     「弹丸数量」在它身上折成伤害（每点 +25%），同样不至于变废卡。
  3. **加粗**：进化宽度 x1.3 → **x1.75**（8 → 14，判定半宽），加外晕之后是一道很粗的光。
- `smoke` 加 9 条断言：进化仍是持续光束 / 加粗 / 不再有多重光栅 / 弹丸数量改不成两道但折成伤害 /
  有目标时常驻 0.16s / 不再往 chains 塞闪线 / 没目标淡出 / 上车也淡出。
  `shots.js` 的 `meltbeam` 步骤同步改写（不再靠延长 chains 生命来"抢帧"）。

### 重做：重型进化的专属机制（并删掉等离子炮）

**结论先说**：重型的 8 条进化现在**每条都有自己的开关**（`smoke` 会核对），不再只是本体的数值放大。

| 进化 | 以前 | 现在 |
|---|---|---|
| 弹幕墙（重机枪） | 弹链穿三人 | **360° 螺旋弹幕**：不再瞄准，每发甩出 36 发一整圈，相位逐发转 |
| 转管风暴（加特林） | 只是射速更快 | **弹丸变大**（判定 + 视觉）+ 伤害 1.35→1.6 |
| 攻城弩阵（攻城弩） | 八矢齐射 | **每支箭命中即炸，穿透的每一段都炸** |
| 湮灭炮（轨道炮） | 更宽的贯穿 | **3 秒蓄力 + 巨粗光柱 + 开火后光柱停留 0.6 秒**（像冲击波一样扩散淡出） |
| 炼狱（重火焰） | 火舌更长 | **烧过的地方留一片火**（火池会点着踩进去的敌人） |
| 血肉磨坊（重链锯） | 伤害更高 | **自带撕裂**：不用点「锯齿刃口」也每口叠流血 |
| 焚城（重RPG） | — | 已有：破片（`shard`） |
| 剑刃风暴（巨型光剑） | — | 已有：剑气（`beam`） |

- **删除等离子炮 / 恒星炮**：它的 `radius` 一直是死字段（卡面写"附带小范围爆炸"、实际什么都没炸），
  与其补一个"光束末端爆炸"不如直接砍掉 —— 重型里已经有三把能量系（轨道炮 / 火焰 / 加特林），
  它那把"中距离直线"和轨道炮的定位重叠。连带删掉的：进化条目、数据引用、`smoke` 里的爆炸断言。
- **弹幕墙的数值是量出来的**，不是拍的：一圈 36 发 × 3.3 环/秒 = 110 发/秒，单体命中率低，
  所以单发伤害按 3.25 倍补偿（Lv3 实测：单体 149 / 扇面 1086 / 环形 1189；
  同口径下本体 Lv5 是 135 / 143 / 145）。
- **湮灭炮的蓄力不叠冷却**：`chargeTime` 接管节奏之后不能再叠 `st.cd`，
  否则 3 秒蓄力 + 3 秒冷却 = 6 秒一发，实测 8 秒只能打出 1 发（DPS 直接腰斩）。
- **渲染新增**：螺旋弹幕（无新增，复用弹丸）、大号弹丸（光晕 + 曳光 + 白芯）、
  湮灭炮的蓄力阵（三道收束环 + 八根辐条 + 聚能核）与巨粗余辉光柱（两侧拉出电弧、随淡出继续外扩）。
- `smoke` 加 12 条：四个新开关各一条、螺旋弹幕铺满 ≥5 个方向、箭炸波及旁边 24px、
  湮灭炮蓄力 / 约 3 秒一发 / 光柱停留、以及"每条重型进化都有自己的新开关"。
- 顺带修掉一条**随机失败**：楼顶那 8 条断言偶尔全红，根因是 `activate('stairs')` 只在
  `state === 'run'` 时生效，而那一帧可能刚好弹升级界面；现在先收摇杆、再把升级清干净。

### 附：进化"有没有自己的东西"审计

`tools/` 里跑了一遍全量对照（flag / 换色 / 换外观 / 机制字段）：

### 修正：开车时环绕体还挂在车上

- **现象**：带着光剑无人环（或电磁轨道球 / 刀轮 / 火焰环 / 无人机）上车，环绕体照样跟着车跑一圈，
  却一下都不打 —— 看着像还在输出，实际伤害早就停了。
- **根因**：`Auto.update` 驾驶时会跳过所有"挂在人身上"的自动装备（`active = ... && !p.veh`），
  但 `Render.drawAutos` 只判了 `p.autos.length`，没判 `p.veh`，于是照样画。
- **修法**：`drawAutos` 画"挂在身上"的那段（跟随 / 环绕 / 环带 / 支援）时，驾驶中直接 return。
  **已经落地的装置不受影响**（`run.devices`：炮塔 / 地雷 / 区域）—— 它们是真的还在工作，也必须一直看得见。
- `smoke` 加 2 条断言：直接数绘制调用，车上必须是 0 次、下车才有东西画
  （把守卫去掉，这条会立刻变成「15 次绘制」并失败）。

### 删除：迫击炮

- 武器数据、进化「火雨」、专属分支、音效 / 图标 / 外观三张映射表全部移除；
  抛射（lob）+ 破片的管线仍保留并有断言（以后加回同类武器不会变成空包弹）。

## 新增内容

### 核心玩法
- **自动开火肉鸽**：拖动屏幕移动，武器自动索敌开火；单局 6 分钟，死亡即结算
- **升级三选一**：每局随机成长路线——武器等级、专属机制分支、通用属性、新装备、联动、进化六大来源加权抽取，附 2 次重抽保底
- **武器概率按强度设计**：新装备权重由实际战力（输出 / 覆盖面 / 控场 / 功能）换算，最强的比最弱的稀有约 5 倍；
  主武器单独一档抽取，不会被副武器和自动装备稀释；所有武器都不限地图
- **换装不再"逼你换"**：换过一次主武器后，换装卡整档概率减半；每轮三选一必定留一张
  不动手里武器的卡（属性 / 分支 / 联动 / 等级），不会出现三张全是换装
- **深水从"墙"改成"泥沼"**：深水可通行但只有三成速度（载具 0.32 / 普通丧尸 0.34），
  蹚水有涟漪与水花；水鬼在水里 0.95，深水反而成了它的高速通道
- **鱼叉枪真的会拽人**：命中按距离把目标拖近（最多约 100px，停在贴身 26px 外），
  甩出一道锁链、附带 0.16 秒踉跄与铁链声
- **链锁钩爪拽到面前**：钩爪单独配了拖拽参数（贴身 16px 停手、拽掉 90% 距离），
  155px 外一发就进近战距离（实测 150 → 29），同样带锁链与踉跄
- **榴弹发射器改回"打出去"**：不再复用投掷动作，从枪口发射（后坐 + 枪口焰 + 炮口烟），
  手雷、燃烧瓶这些真正的投掷物仍然保留抬手扔的动作
- **电磁轨道球重做**：以前球是"点"，贴脸的敌人打不到（实测单体输出只有光刃的 1/4）。
  现在电球有体积判定（+4px），并每 2.4 秒**过载放电**——朝最近的 4 个目标拉出电弧（满级两颗球、
  6 个目标、间隔 1.6 秒），电弧带电会在积水里继续传导；电球本体也画成了"光晕 + 核心 + 跳动电弧"的带电球
- **处决 = 斩杀**：命中时目标生命低于血线（12% / 17% / 22% / 28%）直接收掉，Boss 免疫、精英阈值减半
- **顺序解锁**：通关当前区域解锁下一张地图
