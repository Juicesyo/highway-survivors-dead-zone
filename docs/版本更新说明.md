## v1.0.1 · 锈水高速

- **第四张地图「锈水高速」**：洪水淹没的立交，浅水减速、深水极慢（可通行），浑浊水面有像素反光与水草。
- **积水导电**：电系攻击会在水面额外跳伤；玩家站在同一片水里也会遭电击，连锁不会递归。
- **固定残骸**：半沉车辆与路边废车都推不动，只能挡子弹、绕开或被 Boss 砸碎；
- **巨斧有了挥砍动作**：交叉斩双斧先拉开蓄力、再横扫出去（带刃光拖尾与身体前压），跃劈落地有砸地姿态；
- **地形破坏改为"砸烂地面"**：不再挖出深水坑，改成碎土坑 + 放射裂纹 + 崩出去的石块，通行不受影响，
  但会把路上的车壳砸碎；
- **路面障碍更杂**：侧翻轿车、桥面瓦砾、半埋排水管混在车流里，车辆摆向也不再一律顺路；
- **尸群会绕水**：被深水挡住时会沿粗网格找路绕过水塘，不会再顶在水岸上原地踏步；
- **地形不再围死**：深水改成只在桥面两侧成片（岸线逐行抖动、可伸出一小截浅滩），
  桥面中间只留圆形死水坑——可走区域 100% 连通，不会再出现把丧尸关在里面的封闭水塘；
- **车辆 360° 朝向**：废弃车辆（含半沉残骸）随机旋转，碰撞也换成旋转矩形，看着停歪就真的撞得到；
- **新升级特效「连锁闪电」**：每 X 次开火蓄一道电弧，从你身上跳到附近多个敌人（X 随等级 6→4→3 缩短，
  伤害按那一发的 40/60/80% 折算，跟着武器一起成长）；带电伤害在积水里还会继续传导到水里的人——包括你；
- **关卡强度递增**：小兵血量按关卡 1.00 / 1.08 / 1.16 / 1.24 递增，并附 0% / 3% / 5% / 8% 抗性
  （只挡实弹、近战、爆炸；火焰、冰霜、持续伤害与破甲不受影响），Boss 仍走自己的倍率；
- **新敌人「水鬼」**：浅水移速加成；能潜渡横穿深水，水下无法被索敌/击中（爆炸除外，被炸会震出水面），浮出前水面只有涟漪；呕酸尸也会混入锈水尸群。
- **新效果事件**：抽水机启动排浅周围深水 18 秒；桥下安全屋开放 12 秒，回复生命并阻挡普通丧尸。
- **新 Boss「断堤巨斧」**：高耐久双斧巨尸。交叉斩有扇形预警，跃劈锁定落点并砸出深水圈，两招都会破坏地形。
- **无尽轮换**扩展为四只 Boss；锈水高速通关奖励 110 金，顺序解锁接在荒漠公路之后。

## 新增内容

### 核心玩法
- **自动开火肉鸽**：拖动屏幕移动，武器自动索敌开火；单局 6 分钟，死亡即结算
- **升级三选一**：每局随机成长路线——武器等级、专属机制分支、通用属性、新装备、联动、进化六大来源加权抽取，附 2 次重抽保底
- **武器概率按强度设计**：新装备权重由实际战力（输出 / 覆盖面 / 控场 / 功能）换算，最强的比最弱的稀有约 5 倍；
  主武器单独一档抽取，不会被副武器和自动装备稀释；所有武器都不限地图
- **换装不再"逼你换"**：换过一次主武器后，换装卡整档概率减半；每轮三选一必定留一张
  不动手里武器的卡（属性 / 分支 / 联动 / 等级），不会出现三张全是换装
- **深水从"墙"改成"泥沼"**：深水可通行但只有三成速度（载具 0.32 / 普通丧尸 0.34），
  蹚水有涟漪与水花；水鬼在水里 0.95，深水反而成了它的高速通道
- **鱼叉枪真的会拽人**：命中按距离把目标拖近（最多约 100px，停在贴身 26px 外），
  甩出一道锁链、附带 0.16 秒踉跄与铁链声
- **链锁钩爪拽到面前**：钩爪单独配了拖拽参数（贴身 16px 停手、拽掉 90% 距离），
  155px 外一发就进近战距离（实测 150 → 29），同样带锁链与踉跄
- **榴弹发射器 / 迫击炮改回"打出去"**：不再复用投掷动作，从枪口发射（后坐 + 枪口焰 + 炮口烟），
  手雷、燃烧瓶这些真正的投掷物仍然保留抬手扔的动作
- **电磁轨道球重做**：以前球是"点"，贴脸的敌人打不到（实测单体输出只有光刃的 1/4）。
  现在电球有体积判定（+4px），并每 2.4 秒**过载放电**——朝最近的 4 个目标拉出电弧（满级两颗球、
  6 个目标、间隔 1.6 秒），电弧带电会在积水里继续传导；电球本体也画成了"光晕 + 核心 + 跳动电弧"的带电球
- **处决 = 斩杀**：命中时目标生命低于血线（12% / 17% / 22% / 28%）直接收掉，Boss 免疫、精英阈值减半
- **顺序解锁**：通关当前区域解锁下一张地图

### 三张地图
| 地图 | 特色 | 区域首领 |
|---|---|---|
| 末世街区 | 白天街道，车壳掩体与楼群搜刮 | 血肉暴君（冲锋 + 召唤尸群 + 楼顶投石） |
| 死区之夜 | 夜视受限、射程 -32%，专属敌人出没 | 扫射暴君（加特林弹幕，枪管概率过热） |
| 荒漠公路 | 直路沙野，持枪匪徒据守 | 猎杀者（三段扑杀 + 狂暴嚎叫召尸，血越少攻越急） |

### 敌人（10 种）
游荡者 / 疾行者 / 爬行者 / 吐酸者 / 扑袭者（蓄力猛扑）/ 呕酸尸（矩形毒液）/ 壮汉 / 持枪匪徒，以及三张地图各一名区域首领；精英与受击变体自动生成。

### 武器与构筑
- **95 件武器**：主武器、副武器、重型武器三槽位，覆盖枪械、能量、爆炸、近战、投掷五大类
- **57 条进化路线**：武器满级后可进化为质变形态（龙息点燃、刀阵回响、导弹齐射…），进化后还有 3 级觉醒继续成长
- **12 套机制升级分支**：每件武器都有专属强化方向
- **23 件自动装备**：无人机、炮台、火焰环、毒雾、黑洞、反弹盾牌、自动装填装置等
- **16 组联动构筑**：属性组合型（暴走 / 近身格斗 / 钢铁意志…）与装备组合型（枪管过热 / 冰火两重天…），流派由你定义

### 载具系统
- 两种可驾驶载具：轿车与皮卡，摇杆驾驶、撞击碾压、耐久损耗、战损贴花
- 车体是实体掩体：敌我子弹都会被车壳阻挡，载具报废时玩家被甩出

### 场景与事件
- 街区楼群可进入搜刮，楼顶有独立物资层
- 空投补给、猎犬夜袭、血月狂潮等局内事件
- 燃烧地面、毒雾、冰霜等环境效果与场景破坏

### 局外成长
- **研究所**：金币永久强化（体质 / 武器训练 / 移速 / 幸运 / 贪婪 / 复活）
- **4 名角色**：士兵（新手）/ 医疗 / 机工 / 幽灵，各自自带武器与天赋
- **档案与成就**：武器图鉴、敌人图鉴、累计成就

### 表现与体验
- 手绘标题封面；其余美术、音效全部由代码程序化生成，包体仅约 600KB
- 全程操作提示、低血警示、双击确认清除存档等防呆细节
