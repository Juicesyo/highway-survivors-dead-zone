# 多平台发布与排行榜

同一份核心代码，同时发 **微信小游戏** 和 **B站 Toy**；玩家数据各存各的，排行榜也各排各的。
本文说清楚三件事：代码怎么分层、数据怎么隔离、排行榜怎么接（含微信侧还没做的部分怎么补）。

---

## 1. 一套核心 + 一层宿主适配

不复制项目，只多一层薄薄的「宿主适配层」。核心玩法、数值、UI 一行都不用为平台改。

```
                ┌───────────────────────────────┐
                │  核心（两边完全共用，同一份文件）  │
                │  src/game/*  src/data/*  src/world/*  │
                └───────────────┬───────────────┘
                                │ 只认 HS.Host 的四个能力
                ┌───────────────┴───────────────┐
                │        src/host/host.js        │  门面：探测宿主 / 缓存 / 退避 / 分数换算
                └───┬───────────┬───────────┬───┘
                    │           │           │
              host/wx.js   host/toy.js   host/web.js
              微信小游戏     B站 Toy     浏览器 / Node（开发调试）
```

| 文件 | 职责 |
| --- | --- |
| `src/host/host.js` | 宿主探测、`Rank` 状态机、榜单缓存、分数换算、云存档门面、前后台回调 |
| `src/host/toy.js` | 官方 SDK：`submitScore` / `getRankList` / `getMyRank` / 云存储 + 限流退避 |
| `src/host/wx.js` | 存档走 wx storage；排行榜待接入（两条路线见第 5 节） |
| `src/host/web.js` | 浏览器 / Node：本机记录当榜单，开发时能跑通「提交 → 拉榜 → 我的名次」 |

业务代码里不出现 `wx.xxx` 或 `window.toy`，只调：

```js
HS.Host.id            // 'wx' | 'toy' | 'web' | 'node'
HS.Host.loadRank(period, force)
HS.Host.submitRun(run, cb)
HS.Host.cloudGet(keys, cb) / cloudSet(items, cb)
HS.Host.onHide(fn)
```

四个 adapter 都写进 `game.js` 的 require 列表，**两个平台的包体内容完全一致**，
运行时按环境自己挑；`tools/build-toy.js` 与微信打包都只是「按 require 顺序把文件拼起来」，
不存在第二份需要同步的代码。

## 2. 用户数据怎么隔离

靠宿主本身隔离，不靠"两个项目"：

| 数据 | 微信小游戏 | B站 Toy |
| --- | --- | --- |
| 本地存档 | `wx.setStorageSync('hsdz_save_v1')` | 页面 `localStorage['hsdz_save_v1']` |
| 云存档 key | `hsdz1.wx.save`（待接入） | `hsdz1.toy.save` |
| 排行榜 | 平台按小程序隔离（待接入） | 平台按 **Toy + 榜位 + 周期** 隔离 |
| 身份 | openid（云开发）/ 开放数据域 | `toyOpenId`（平台给的假名，不给 UID） |

- 本地这一层天然物理隔离：一个是原生 storage，一个是浏览器 storage。
- 云端 key 里带宿主前缀（`HS.Host.storageKey('save')`），即使以后两边共用一个后端也不会串。
- 排行榜的数据在平台侧，代码里不存在"把微信玩家和 B站玩家排到一起"的可能。

云存档只做两个关键节点，不是实时同步：**启动拉一次**（云端 `updatedAt` 比本地新才覆盖，换设备不丢进度）、
**结算 / 切后台推一次**。游玩过程中不写，因为 Toy 的云能力是整个作品共享额度的。

## 3. 排行榜：无尽模式存活时间

只有**无尽模式**进榜。普通关卡的 6 分钟是固定流程，比不出高下。

- **榜位**：1 号榜（平台每个作品 1–3 号榜，2/3 号先空着，以后要按地图拆榜再用）。
- **分数**：`Math.round(秒 × 100)`，整数百分秒。`16777215` 上限 ≈ 46 小时，打不满；
  百分秒足够在「同分」时分出先后。
- **周期**：总榜 / 周榜 / 日榜，只是查询时的 `period` 参数，提交一次就够（平台自己按周期记）。
- **展示**：前 10 名 + 我的名次（`getMyRank` 的 `ranked` 才是"是否上榜"，不能看分数是不是 0）。
- **提交时机**：`finishRun` 里，仅 `run.endless` 为真时提交一次。幂等，只增不减。
- **限流**：Toy 的云能力按作品共享额度，所以
  - 榜单拉一次缓存 30 秒，不轮询；刷新靠用户点按钮；
  - 云存档只在结算 / 切后台落盘；
  - 撞到 `307044` 时指数退避（700ms → 1400ms，最多 2 次），并在结算页给出「稍后再试」。

三种失败都有人话提示：未登录（`登录 B站 后才会出现在榜上`）、限流（`请求太频繁`）、
宿主不对（`不在 B站 里打开，榜单不可用`）。

## 4. 微信侧还要做什么

`src/host/wx.js` 目前 `rankSupported: false`，进排行榜页会显示明确提示（不会白屏）。
要接上有两条路，都属于"只改这一个文件 + 一个平台侧工程"：

### A. 开放数据域好友榜（适合"好友之间比一比"）

- 主域：`wx.setUserCloudStorage({ KVDataList: [{ key: 'endless', value: String(score) }] })`
- 开放数据域：新开 `openDataContext/` 子工程，`wx.getFriendCloudStorage` 拉好友成绩，
  画在 `sharedCanvas` 上，主域 `drawImage` 贴到排行榜页
- 限制：只能比好友、只能在微信里跑（网页与 Node 都验不了），需要在 `project.config.json` 里声明

### B. 云开发全服榜（和 Toy 的榜同构，推荐）

- 云函数 `rank`：`action: 'submit' | 'list' | 'me'`，数据放云数据库（collection `hsdz_rank`）
- 主域取 openid 用 `cloud.getWXContext()`，不需要用户授权弹窗
- 玩家看到的是全服名次，和 Toy 侧体验一致；代价是要开通云开发环境（env 由你填）

两条路实现完，把 `rankSupported` 改成 `true`，`list / me / submit` 按 `toy.js` 的返回结构
（`{rank, score, nickname, avatar}` / `{ranked, rank, score}` / `{score}`）填上即可，UI 不用动。

## 5. 发版流程

### B站 Toy

```bash
node tools/build-toy.js          # → dist/toy/（入口 index.html + app.js + bgm/）
python <toy skill>/toy_doctor.py dist/toy
toy update <id> dist/toy --json  # 先出预览，不提交
toy update <id> dist/toy --json --yes   # 确认后提交审核
```

- 入口 `index.html` 必须 ≤ 1MB（当前 ~1KB，代码在 `app.js`，BGM 走外部文件）。
- `index.html` 里 **SDK 脚本要早于 `app.js`**：
  `<script src="https://s1.hdslb.com/bfs/seed/toy/app/sdk/toy-sdk.js"></script>`
- 资源全部相对路径（页面跑在 `/toy/<slug>/` 子路径下）。

### 微信小游戏

1. 微信开发者工具打开仓库根目录（入口 `game.js`，`game.json` 已声明竖屏）。
2. `project.config.json` 里把 `touristappid` 换成真实 AppID。
3. 上传 → 提交审核。包体大小 = 源码 + `assets/sprites.png` + `bgm/bgm.mp3`。

### 同一套代码，两处只差宿主

| | 微信 | Toy |
| --- | --- | --- |
| 入口 | 根 `game.js` | `dist/toy/index.html` + `app.js` |
| 额外脚本 | 无 | `toy-sdk.js` |
| 排行榜 | 待接入（第 4 节） | 平台原生 |
| 存档 | wx storage | localStorage + 云存档 |
